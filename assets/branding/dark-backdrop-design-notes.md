# Dark backdrop concepts

Open dark-backdrop-study.html in a browser. It is self-contained, including the original dark logo and Inter fonts. Use the three tabs to change the backdrop system and the theme switch to test it against light and dark application surfaces. Arrow keys move between tabs.

## Directions

- Compact tile: navy square behind the symbol, with live theme-colored lettering beside it. Lowest impact on the existing interface.
- Logo capsule: the symbol and lettering share one dark rounded capsule. Launch uses a larger dark plaque on the application background.
- Dark brand panel: the entire brand zone stays navy. Headers and authentication get dark brand panels, and native splash stays fully navy.

## Placement coverage

Public web headers (including shared links), signed-in sidebar, compact rail and toolbar, mobile home top bar, web and mobile authentication (sign-in, sign-up, reset password), footer, native launch, web launch/loading, iOS icon, Android adaptive icon, favicon, and touch/PWA icon. Small inline marketing marks use the compact navy tile.

The navigation shown is illustrative. These files are design concepts; no application changes are applied by opening them.

## Recommendation

Use compact tiles for product headers and authentication, with a full midnight splash. Keep the navy launcher icon and favicon across themes. This gives the existing logo a consistent background without turning the whole light interface dark.

The screenshots capture each direction in light mode, the compact-tile direction in dark mode, and the capsule design at phone width. The interactive HTML includes all six direction/theme combinations.
