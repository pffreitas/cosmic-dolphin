# Purple-black capsule refinement

Open purple-black-capsule-study.html in any browser. The interactive study is self-contained. Select a finish and switch application themes to review all web and mobile placements.

## Finishes

All gradients run at 125 degrees, with stops at 0%, 48%, and 100%.

- Black violet (recommended): #29153C → #100B1C → #030408; edge #3D2B52.
- Indigo night: #211B43 → #0A0A19 → #030409; edge #363052.
- Plum shadow: #34162F → #160D1B → #050509; edge #49273E.

The existing dolphin shape and colors are unchanged. Only the background treatment changes. Header and sign-in lockups use a capsule; compact placements use a rounded tile; native splash uses a larger plaque. Launcher icons retain platform-applied masks.

## PNG exports

- header-*.png: complete wordmark capsules with transparent corners.
- tile-*.png: 256px compact tiles with transparent corners.
- icon-*.png: opaque 1024px launcher assets; no baked rounded corners.
- splash-plaque-black-violet.png: standalone transparent-corner launch plaque.
- splash-light-black-violet.png and splash-dark-black-violet.png: 1290 × 2796 portrait compositions.

The PNGs are review assets, and the HTML is a placement concept. Product components are not changed by opening it. The original logo remains intact.

## Rebuild in the repository

Run node scripts/build-brand-backdrop-study.mjs, then node scripts/build-purple-capsule-study.mjs.
