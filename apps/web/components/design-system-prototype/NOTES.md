# Design System Prototype Notes

## Question

Which visual direction should become the canonical Cosmic Dolphin design system for future web and mobile work?

## Prototype Scope

- `blue`: Blue-Cyan Editorial Intelligence
- `amber`: Amber Editorial Warmth
- `mono`: Near-Monochrome Precision
- Screens shown for each option: Home feed, Library, Bookmark detail
- Data is mocked and local to the prototype.
- No persistence, API calls, or production behavior.
