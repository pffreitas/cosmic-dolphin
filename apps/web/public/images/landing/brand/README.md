# Landing-page identity

Derived from the approved original-artwork refinement in
`docs/design-system/prototypes/original-logo-refinement/`.

- `compact.webp`: 128px version of the compact dolphin artwork, for the header, footer and the
  closing lockup.
- `wordmark-dark.webp`: transparent raster export of the Avenir Next Demi Bold wordmark with light
  lettering. It is only ever shown on `--cd-brand-ground`.

Regenerate with `python3 docs/design-system/prototypes/original-logo-refinement/prepare-landing.py`
from the repository root (Pillow and the macOS Avenir Next font required).
The font itself is not bundled. The original mobile icon remains the source artwork.
