# Cosmic Dolphin identity standards

The flat Gargantua v0 symbol is the approved logo. Its geometry and colour treatments are specified in the [client manual](surface-guide.pdf). The [screen edition](surface-guide.html) includes reduction specimens at their stated CSS pixel widths.

Download the [complete identity kit](Cosmic-Dolphin-v0-Identity-Kit.zip) for the manual, offline HTML edition, five master SVGs and four 1,024 px PNGs. The [source artwork](ring-gargantua/README.md) is maintained alongside the design history.
