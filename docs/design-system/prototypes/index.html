Cosmic Dolphin · Design System

Three directions, one system

A calm, intelligent reading network.

Cosmic Dolphin turns saved links into things people actually read. Everything below is the same design system — same tokens, same components, same layouts — rendered in three visual directions. Switch between Signal, Ember, and Graphite in the header, and flip light/dark to check both. Pick one; the rest becomes the spec.

Direction A

Signal

Deep blue-cyan on cool neutrals. Feed items are bordered panels. AI carries an accent rail. The most explicitly "product" of the three — closest to Linear.

Direction B

Ember

Amber on warm paper. Separator rows instead of boxes, a bookish serif, and italic editorial labels. The most reading-room of the three — closest to Craft.

Direction C

Graphite

Near-monochrome with color reserved for state. Hairlines, mono metadata, a sharp display serif. The most precise of the three — closest to Vercel.

Fixed across all three

voice
Serif for content the user is evaluating; sans for everything they operate. Never a serif button, never a sans bookmark title.
surfaces
Borders and separators, not elevation. Shadows only for things that genuinely float: dialogs, popovers, command palette.
shape
8px content surfaces, 6px compact controls, 12px on the app frame and the AI callout. Pills for the header capsule, tags, avatars, segmented filters, and the primary CTA.
ai
A quiet editorial layer, never a mascot. Every AI output shows its source and offers "why this appeared".
social
Present but secondary. One compact action row; conversation expands on demand and never runs inline in the feed.
density
Medium. Scannable like YouTube, calmer than a dashboard. One clear title per item, one summary, one action row.

The Bottleneck Was Never Retrieval

Eevery.to Dan Shipper saved 2d ago 9 min read
Cosmic brief 9 min article · read in 40 seconds

Retrieval quality has become a distraction. In the author's testing, agents with excellent search still looped on solved sub-problems because nothing recorded what had already been attempted. The fix is a cheap episodic log, not a better index.

Key points

  • Retrieval accuracy above ~85% stops predicting task success.
  • Repeated-action loops account for most failed long-horizon runs.
  • An append-only attempt log outperformed a 4× larger context window.
Eevery.to summarised from the full article

Every team that has shipped an agent to production tells a version of the same story. They spend a quarter tuning the retriever, celebrate the eval bump, and then watch the thing stall on a task it had already half-solved forty seconds earlier. The documents were there. The model found them. It just had no idea it had been here before.

It is worth being precise about what memory means here, because the word has been stretched to cover everything from a vector store to a system prompt. What is missing is not semantic recall…

An agent that cannot remember its own failures is not an agent. It is a very expensive retry loop.

06

Rules for implementers

Tokens and components are strict. Page composition is yours. When a new screen needs something not listed here, extend the token set first and the component second — never inline a value.

Non-negotiable

serif
Content titles and pull quotes only. Feed titles, library titles, detail titles, headings inside saved content.
sans
Nav, buttons, metadata, tags, comments, forms, empty states, every count.
colour
Semantic tokens only. Accent is for active nav, links, AI provenance and selected states — not decoration.
shadow
The header capsule, dialogs, popovers and the command palette. Nothing in a feed or list may float.
a11y
4.5:1 on body text, visible focus ring on every interactive element, reduced-motion honoured by all progress and shimmer.

Where things live

tokens
CSS variables in apps/web/app/globals.css, mirrored to Tailwind theme keys and re-exported for apps/mobile.
primitives
Radix + components/ui. Restyle the primitive; never fork it per screen.
patterns
Header capsule, feed item, library row, provenance row, AI callout, social row and staged progress ship as shared components.
data
Provenance comes from metadata.openGraph + sourceUrl; summaries from cosmicBriefSummary; tags from cosmicTags; filing from collectionPath.
states
Every list needs four: loading skeleton, empty, error, and AI-processing. Ship all four or the pattern is incomplete.
