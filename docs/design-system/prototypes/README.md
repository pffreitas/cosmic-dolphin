# Historical prototypes

These are exploration artifacts, not the current web reference. In particular `index.html`'s
Signal mode still shows the retired blue palette and older typography. Ember and Graphite were
never adopted. Mobile explorations also predate the approved Save + Today’s 5 scope.

Use the current web `/dev/patterns`, `/dev/library`, `/dev/bookmark` and `/dev/home` fixtures,
then actual product routes for behavior. The reusable specifications live in the parent directory;
[parity.md](../parity.md) defines authority and visual verification. Do not copy styles from these
HTML files into either client.

The original self-contained files remain openable directly for historical comparison. Logo and
landing studies in this directory are experiments unless the current implementation uses them.
